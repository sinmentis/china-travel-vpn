# 05 - 确认能用，用完停止计费

[English](05-testing-and-teardown.md) · **中文**

手机出现 VPN 图标，还不能算完成。先确认流量真的按预期走；
用完之后，记得删掉那台还在计费的服务器。

## 26. 出发前看这几项

- [ ] 服务器重启过，`xray` 和 `nftables` 都在运行。
- [ ] [伪装检查](03-vless-reality.zh-CN.md#camouflage)仍然通过。
- [ ] 客户端能通过隧道打开网站，出口 IP 是服务器的地址。
- [ ] 预期会用的网络都试过，包括 Wi-Fi 和蜂窝网络。
- [ ] 国内直连规则和 DNS 行为与客户端设置一致。
- [ ] 可用的客户端配置和 SSH 私钥已经备份。

完整的 bring-up 脚本已经做过服务器重启和客户端测试，不用为了勾选再重启一次。
在境外做完这些检查，也仍然不能证明国内的线路表现。

## 27. 知道怎么替换服务器

不用为了完成搭建，先把正在用的机器删一次。
想演练换机的话，按[替换流程](../TROUBLESHOOTING.zh-CN.md#replace-server)做：
先开新机，确认可用，再删旧机。

这里要分清楚：`bring-up.sh` 会复用配置里同名的实例。
再跑一次，不等于拿到新 IP。

## 28. 用完之后

用脚本部署的，在原来的仓库目录运行。先看它准备删哪台：

```bash
./scripts/bring-down.sh --dry-run
```

核对标签和 IP。确认要永久删除这台实例后，再执行：

```bash
./scripts/bring-down.sh --yes
```

手工部署的，直接在 Vultr 点 **Destroy**。
确认实例已经消失，也看看账单里有没有其他资源。
删除会停止这台实例后续的计费，不会抹掉已产生的费用，也不会删除单独计费的存储或快照。

销毁脚本会保留可复用的 SSH 和 REALITY 凭据。
以后不再需要自动化时，把 API key 撤销。
预览不会改本地文件，找不到实例时也一样。
只有确认删除成功，或显式用 `--yes` 清理已不存在的实例记录，才会清理本地状态。

## 赠金要看到期日

Vultr 关机仍然收费。赠金会过期，也不代表账号变成了用完即停的预付费服务。
至少在显示的到期日前一天安排销毁；页面没写时区，就再多留一些余量。

[余额保护脚本](../scripts/vultr-credit-guard.sh)会检查剩余额度是否达到
`CREDIT_GUARD_MIN_REMAINING`（默认 `$1`），或是否已到必填的 UTC 截止时间
`CREDIT_GUARD_DEADLINE`，格式为 ISO 8601（`YYYY-MM-DDTHH:MM:SSZ`）。
它只处理配置的 `personal-vpn-` 前缀实例，不管理其他计费资源。

脚本每运行一次只查一次。要每天执行，需要在一台持续在线的机器上另配 systemd timer 或 cron，
`bring-up.sh` 不会安装这个定时任务。API 访问也必须一直有效。
试运行时用 `CREDIT_GUARD_DRY_RUN=1`，预览不会覆盖上一次实际运行的状态。
API 数据异常会报错，不会当成空账号继续处理。
它仍是防忘记的措施，不是云厂商强制执行的消费上限。

已到配置的截止时间后，销毁不再依赖余额接口，但实例列表仍须有效。
模拟时间（`CREDIT_GUARD_NOW_EPOCH`）只允许在预览模式使用。
